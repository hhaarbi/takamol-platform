# منصة تكامل — شركة هاشم عبد الحكيم للاستشارات الهندسية

نظام إدارة متكامل لمكتب الاستشارات الهندسية يشمل إدارة المواعيد، التواصل مع العملاء، التسعير الداخلي، وتكويد المعاملات مع سير عمل آلي بين الأقسام.

---

## المكونات الرئيسية

| الوحدة | الوصف |
|---|---|
| **المصادقة والصلاحيات** | تسجيل دخول بالمستخدم وكلمة المرور، أدوار متعددة، صلاحيات مخصصة |
| **إدارة العملاء** | سجل موحد لكل عميل مع تاريخ مواعيده وتسعيراته ومعاملاته |
| **إدارة المواعيد** | حجز مواعيد مع فرز مسبق، كشف التعارضات، الأوقات المتاحة |
| **التواصل والتذاكر** | نظام تذاكر مرتبط بالعملاء مع توجيه آلي للأقسام |
| **التسعير الداخلي** | مسودة تسعير يدوية → اعتماد المدير → موافقة العميل |
| **تكويد المعاملات** | تحويل التسعير لمعاملة مكودة (LIC-26-001) مع سير عمل تلقائي |
| **إدارة الخدمات** | قائمة خدمات مرنة مصنفة حسب الأقسام |

---

## هيكل الأدوار والصلاحيات

| الدور | الصلاحيات |
|---|---|
| `super_admin` | صلاحية كاملة على كل شيء |
| `admin` | إدارة المستخدمين والنظام |
| `dept_head` | رؤية معاملات وموظفي قسمه فقط |
| `engineer` | رؤية مهامه ومواعيده فقط |
| `sales` | إنشاء عملاء وتذاكر وتسعيرات |
| `accountant` | تأكيد الدفعات في سير العمل |

## تدفق العمل (Workflow)

```
العميل يتصل/يزور
        ↓
حجز موعد (مع فرز مسبق)
        ↓
إنشاء مسودة تسعير (يدوي)
        ↓
إرسال للاعتماد → مدير القسم يعتمد
        ↓
إبلاغ العميل بالسعر (واتساب)
        ↓
موافقة العميل → تحويل لمعاملة مكودة
        ↓
محاسبة: تأكيد الدفعة الأولى
        ↓
الأقسام المعنية (مساحة → تصميم → رخص)
        ↓
تسليم نهائي وإغلاق المعاملة
```

## تشغيل المشروع

### المتطلبات
- Node.js 18+
- PostgreSQL 14+

### الخطوات

```bash
# 1. نسخ المشروع
git clone https://github.com/hhaarbi/takamol-platform.git
cd takamol-platform

# 2. تثبيت التبعيات
npm install

# 3. إعداد متغيرات البيئة
cp .env.example .env
# عدّل ملف .env بمعلومات قاعدة البيانات

# 4. إنشاء قاعدة البيانات
createdb takamol_db

# 5. مزامنة الجداول
npm run migrate

# 6. إدراج البيانات الأولية (الخدمات + حساب المدير)
npm run seed

# 7. تشغيل الخادم
npm start
```

## نقاط API الرئيسية

### المصادقة
| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/api/v1/auth/login` | تسجيل الدخول |
| GET | `/api/v1/auth/me` | بيانات المستخدم الحالي |
| POST | `/api/v1/auth/users` | إنشاء موظف جديد (admin) |

### المواعيد
| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/v1/appointments` | قائمة المواعيد |
| POST | `/api/v1/appointments` | حجز موعد جديد |
| GET | `/api/v1/appointments/available-slots` | الأوقات المتاحة |
| PUT | `/api/v1/appointments/:id/reschedule` | إعادة جدولة |

### التسعير
| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/api/v1/quotations` | إنشاء مسودة تسعير |
| PUT | `/api/v1/quotations/:id/submit` | إرسال للاعتماد |
| PUT | `/api/v1/quotations/:id/approve` | اعتماد (مدير) |
| PUT | `/api/v1/quotations/:id/client-accept` | تسجيل موافقة العميل |

### المعاملات
| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/api/v1/transactions/convert` | تحويل تسعير لمعاملة |
| GET | `/api/v1/transactions` | قائمة المعاملات |
| PUT | `/api/v1/transactions/:id/complete-stage` | إكمال مرحلة |
| GET | `/api/v1/transactions/dashboard` | إحصائيات الإدارة |
